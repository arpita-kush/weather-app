# 🌦️ Weather App

A responsive weather application built using HTML, CSS, JavaScript, and WeatherAPI.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature
- 🌤️ Weather condition and icon
- 💧 Humidity information
- 💨 Wind speed
- 🌡️ Feels-like temperature
- 🕐 Local time of the searched location
- 📅 3-day weather forecast
- 📍 Use my location
- 🌙 Dark/Light mode
- 🖼️ Dynamic weather backgrounds
- 💾 Remembers the last searched city
- 📱 Responsive design
- ❌ Invalid city/error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Add your WeatherAPI key in `script.js`.
4. Open `index.html` in your browser.
